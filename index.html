      AI 模型配置

      配置 AI 大模型 API，用于车型搜索和智能分析。支持所有兼容 OpenAI Chat Completions 格式的 API。

      API 端点

      API 的 Base URL，例如：
      • 豆包：https://ark.cn-beijing.volces.com/api/v3
      • OpenAI：https://api.openai.com/v1
      • DeepSeek：https://api.deepseek.com/v1
      • 通义千问：https://dashscope.aliyuncs.com/compatible-mode/v1

      模型名称

      模型标识符，例如：
      • 豆包：doubao-seed-1.6 / doubao-pro-32k
      • GPT-4o：gpt-4o
      • DeepSeek：deepseek-chat
      • 通义千问：qwen-plus

      API Key

      你的 API 密钥，仅存储在本地浏览器中，不会上传到服务器。

      模型联网搜索

      启用后，AI 分析时会自动联网搜索最新车型评测和优惠政策。
      已支持：千问（Qwen）系列、通义千问、豆包、火山引擎、DeepSeek 等主流联网模型。
      关闭时使用模型训练知识库。无需额外配置 API，由模型自身提供联网能力。

      Thinking 模式（深度推理）

      启用后 AI 会进行更深入的思考分析，结果更准确，但响应速度会变慢。
      支持的模型：DeepSeek R1、QwQ、OpenAI o1/o3 等。
      如果当前模型不支持，系统会自动回退到普通模式并提醒您。

      当前模型可能不支持 Thinking 模式，已自动回退到普通模式。如需使用深度推理，请切换到 DeepSeek R1、QwQ 或 OpenAI o1/o3 等模型。
